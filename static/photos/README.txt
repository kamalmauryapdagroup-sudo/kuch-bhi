Drop your photos in this folder with these exact filenames and they'll
appear automatically — no code changes needed:

  memory1.jpg   (used in the "girl behind the smile" page + first scrapbook slot)
  memory2.jpg   (scrapbook slot 2)
  memory3.jpg   (scrapbook slot 3)
  memory4.jpg   (scrapbook slot 4)

If a file is missing, the page just shows the soft placeholder text instead
of breaking — so you can add photos gradually, or send the site as-is and
fill these in later.

Tip: square-ish or portrait photos (roughly 4:5) will look best in the frames.

To edit the captions under each scrapbook photo, open app.py and search
for "Add a caption here" — there are four of them, one per photo.

Add a background music track named exactly:

  bg-music.mp3

Put it in this folder. A small round music button will automatically
appear in the top-right corner of every page once the file is found,
so she can turn it on or off herself (it does not autoplay, since
browsers block that anyway — a tap starts it).

Pick something you know she likes, or something meaningful to you two.
Keep the file reasonably small (under ~5MB) so the page loads fast.
If you don't add a file, the music button simply stays hidden.
